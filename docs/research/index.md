# Research Notes

Data-source research notes that inform Teamarr's provider and league decisions.
Each page is a point-in-time investigation — API endpoints validated, data shapes
captured, feasibility verdicts reached — preserved here so future provider/league
work doesn't have to rediscover it. Dates and "live right now" remarks reflect
when the research was done, not the current state.
