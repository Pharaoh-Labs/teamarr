# User Guide

Step-by-step guides for using Teamarr.

The app's navigation is numbered to walk you through setup in order (the numbers appear on first run and drop off as you visit each step). Follow the same order here:

![Numbered navigation steps in the top bar](../assets/images/nav-steps.png)

| Step | Page | What you do |
|------|------|-------------|
| 0 | [Settings](settings/) | Connect Dispatcharr, set timezones and schedule |
| 1 | [Sources](sources/) | Import M3U stream groups as sources |
| 2 | [Subscriptions](subscriptions) | Pick which leagues and sports to match |
| 3 | [Matching](matching/) | Tune EPG matching, lookahead, and custom rules (optional) |
| 4 | [EPG](epg/) | Build templates that control channel names and guide content |
| 5 | [Channels](channels/) | Control lifecycle, numbering, grouping, and stream priority |
| — | **Generate** | Run it — then watch results on the [Dashboard](dashboard) |

Start with [Installation](installation), then [Dispatcharr Integration](dispatcharr-integration) for the initial connection walkthrough.
